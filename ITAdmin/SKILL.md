Skill: Administracja sieciami Windows / UNIX / Active Directory

Opis:
Kompetencja w pełnej administracji systemami Windows Server i Linux/Unix, zarządzaniu Active Directory, usługami sieciowymi, automatyzacją oraz bezpieczeństwem infrastruktury IT.

Zakres:
- Active Directory: OU, GPO, delegacja uprawnień, LDAP, polityki bezpieczeństwa
- Windows Server: DNS, DHCP, SMB, IIS, NPS, DFS, administracja WS 2012–2022
- Linux/Unix: SSH, Apache/Nginx, Samba, cron, systemd, firewall (iptables/firewalld)
- Automatyzacja: PowerShell, Bash, konfiguracja i skrypty administracyjne
- Sieci: TCP/IP, routing, DNS, VPN (IPsec, OpenVPN, WireGuard)
- Bezpieczeństwo: hardening CIS, auditing, logi systemowe, inspekcja zdarzeń
- Diagnostyka: analiza logów AD i Linux, narzędzia systemowe, wskaźniki wydajności

Zastosowania:
- generowanie skryptów i automatyzacja administracji
- projektowanie infrastruktury Windows/Linux
- rozwiązywanie problemów systemowych i sieciowych
- tworzenie polityk GPO i procedur IT
