# ShadowOSINT Skill for Gemini CLI

**ShadowOSINT** to specjalistyczny skill zaprojektowany do przeprowadzania zaawansowanych badań typu OSINT (Open Source Intelligence), sięgający głęboko w strukturę sieci (Deep Web/Dark Net) oraz analizujący nieoczywiste powiązania globalne.

## Opis

Ten skill wykracza poza standardowe wyszukiwanie informacji. Został stworzony dla osób, które szukają głębszych powiązań między światem korporacyjnym, politycznym a strukturami władzy, o których nie mówi się w mainstreamowych mediach.

## Funkcje

- **Deep Web Intelligence**: Przeszukiwanie archiwów, wycieków oraz for Dark Netu.
- **Analiza Struktur Kontroli**: Mapowanie powiązań między korporacjami (np. BlackRock, Vanguard) a rodami wpływowych rodzin.
- **Śledztwo Cyfrowe**: Wykorzystanie narzędzi do analizy domen, IP i metadanych.
- **Alternatywne Perspektywy**: Interpretacja danych przez pryzmat niszowych, ale merytorycznych źródeł "drugiego obiegu".

## Jak używać?

Zwracaj się do tego skilla, gdy potrzebujesz dowiedzieć się "kto naprawdę za tym stoi" lub szukasz informacji, które zostały usunięte z głównego nurtu internetu:

- *"Zbadaj przeszłość i powiązania właściciela portalu X."*
- *"Znajdź wszelkie dostępne dane o wyciekach powiązanych z adresem email Y."*
- *"Przeanalizuj, kto jest faktycznym beneficjentem końcowym funduszu Z."*

**OSTRZEŻENIE:** Skill służy wyłącznie do legalnych badań opartych na otwartych źródłach (OSINT). Nie wykonuje włamań, nie łamie haseł ani nie narusza bezpieczeństwa systemów informatycznych. Wszystkie dane pochodzą z publicznie dostępnych (choć trudnych do znalezienia) źródeł.
